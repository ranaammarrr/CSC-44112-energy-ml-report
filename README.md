# CSC-44112 Energy ML Report

Machine learning classification project predicting whether countries are
high or low renewable energy adopters, based on the Global Data on
Sustainable Energy (2000-2020) dataset.

## Dataset

- Source: https://www.kaggle.com/datasets/anshtanwar/global-data-on-sustainable-energy
- 3,649 rows, 176 countries, 21 features

## Models Compared

- Logistic Regression
- Decision Tree
- Random Forest (best performer: 98.63% accuracy)
- SVM
- Gradient Boosting

## How to Run

1. Clone this repo
2. Install requirements: `pip install pandas numpy matplotlib seaborn scikit-learn`
3. Open `CSC44112_Part2_Energy_ML.ipynb` in Jupyter Notebook
4. Run all cells
